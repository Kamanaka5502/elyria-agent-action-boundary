# Deployment Modes

## Purpose

This document explains how the Elyria Agent Action Boundary can be used from public-safe demo through enterprise pilot planning.

---

## Mode 1: Local Sandbox

Run the repository locally to evaluate sample agent scenarios.

```bash
python sandbox/run_sandbox.py
```

Use this mode for:

- portfolio review
- hiring-panel demonstration
- architecture explanation
- basic scenario validation

---

## Mode 2: Workshop Demo

Use the README, demo script, sandbox scenarios, and sample report in a guided discussion.

Use this mode for:

- CIO / CISO / CTO briefings
- AI governance discovery
- security architecture discussions
- responsible AI workshops
- buyer education

---

## Mode 3: Pilot Readiness Review

Use the checklist, authority matrix, and sandbox outputs to evaluate a real enterprise agent candidate.

Use this mode for:

- agent tool-use review
- RAG-plus-agent review
- workflow automation review
- production-candidate readiness
- approval and refusal boundary design

---

## Mode 4: Enterprise Adaptation

Adapt the public-safe reference model to a specific enterprise environment.

Required additions:

- identity and access integration
- logging and SIEM integration
- policy and risk taxonomy
- approval workflow integration
- tool registry integration
- production incident path
- privacy and legal review
- change-management linkage

---

## Mode 5: Production Control Pattern

Production use requires environment-specific implementation and validation.

This public repository should be treated as a reference architecture and pilot sandbox, not as a complete production enforcement system.
