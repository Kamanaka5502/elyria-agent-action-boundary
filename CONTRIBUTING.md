# Contributing

## Public-Safe Contributions Only

Contributions should strengthen the public-safe enterprise agent action boundary model.

Accepted contribution types:

- documentation improvements
- scenario examples without private data
- clearer decision logic explanations
- sandbox usability improvements
- enterprise readiness checklist improvements
- public-safe test expectations

Do not contribute:

- credentials
- customer data
- private client artifacts
- protected Elyria Systems runtime machinery
- confidential diagrams
- proprietary implementation internals
- production logs

## Review Standard

A contribution should preserve the repository purpose:

```text
Govern what an AI agent may access, call, change, escalate, or refuse before tool use becomes enterprise consequence.
```

## Decision Language

Use the repository decision model consistently:

```text
ADMIT / HOLD / REFUSE / REVALIDATE
```
